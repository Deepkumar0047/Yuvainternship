# Week 4 – Enhancing Web Page Performance and Accessibility

## Project Overview

This project focuses on improving the **performance, accessibility, and usability** of a static coffee shop webpage named **Brew Haven**.

The webpage was optimized using HTML5 and CSS3 while following modern web development and accessibility practices.

## Objectives

* Improve webpage loading performance.
* Use proper semantic HTML structure.
* Make the webpage accessible to users with disabilities.
* Improve keyboard navigation and screen-reader support.
* Reduce unnecessary CSS redundancy.
* Make the webpage responsive on different screen sizes.
* Follow basic web accessibility guidelines.

## Key Improvements

### Performance

* Optimized image loading and dimensions.
* Reduced unnecessary CSS repetition.
* Used reusable CSS classes.
* Avoided unnecessary libraries and JavaScript.
* Added responsive design for different devices.
* Used lightweight HTML and CSS.

### Accessibility

* Added semantic HTML5 elements.
* Added meaningful alternative text for images.
* Added a skip-to-content link.
* Used proper heading hierarchy.
* Added labels to form fields.
* Added visible keyboard focus indicators.
* Used appropriate ARIA attributes.
* Added support for reduced motion.
* Improved readability and color contrast.

## Testing Tools

The webpage can be tested using:

* **Lighthouse** – Performance, accessibility, SEO, and best-practice testing.
* **WAVE** – Accessibility and structural testing.
* **axe DevTools** – Detection of common accessibility issues.
* **WebPageTest** – Detailed webpage performance analysis.

## Technologies Used

* HTML5
* CSS3
* Semantic HTML
* CSS Grid
* Responsive Design
* Accessibility Best Practices

## Learning Outcomes

This project helped in understanding the importance of webpage performance and accessibility. It demonstrated how semantic HTML, optimized CSS, accessible forms, keyboard navigation, proper image handling, and responsive design can improve the overall user experience.

## Conclusion

The Week 4 project successfully demonstrates a more **accessible, responsive, lightweight, and user-friendly static webpage**. The improvements make the website easier to use for both regular users and users who rely on assistive technologies.
